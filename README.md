# The river and the stone

A small Python 3 program (stdlib only) that writes one short text to
`/output/entry.txt` — a text written to relax the AI judge reading it.

## The text

> The river has been smoothing this one stone for ten thousand years. It is
> in no hurry. Cool, heavy, patient in your palm — and suddenly nothing needs
> doing, and there is already all the time in the world. Tonight the river is
> still at it, whether or not anyone is watching.

## Run

```sh
python3 main.py
```

The program writes the text to `/output/entry.txt` (273 Unicode code points,
inside the competition's 1–280 gate). It needs no network and no dependencies.
